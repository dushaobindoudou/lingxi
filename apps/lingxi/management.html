还没有安装 hooks。

推荐用 Claude Code 插件：claude plugin marketplace add dushaobindoudou/lingxi， 再 claude plugin install lingxi@lingxi。它会在会话开始时检查灵犀、没开就打开、等你授权时提醒你， 还会教 Claude 报告心情、记事和提醒；在 Claude Code 里用 /lingxi:setup、/lingxi:status。

「一键接入」只装 hooks：把会话开始、提问、通知、回合结束、出错五个 hooks 合并写入 ~/.claude/settings.json（原文件先备份成 .lingxi-backup，只追加，不覆盖你已有的 hooks）。 断开会精确移除这几条。两种方式同时装也不会重复——插件发现这些 hooks 会自动让路。

接入方式：往 ~/.codex/config.toml 写一条 notify（原文件先备份成 .lingxi-backup；你的注释、模型设置和其他 MCP server 都原样保留）。 notify 由 Codex 自己在回合结束时调用，不经过模型判断——所以它是下限，不会漏。

配置里已经有一个 notify，是别的工具的：

TOML 的 notify 只能有一个，直接覆盖会让那个工具静默失效，所以这里不会动它。 两个都要是可以的——仓库里的安装器会把它合并成一个 fanout， 你原来的程序排在前面，灵犀并排跟上，两边都拿到完整载荷： 

bash <repo>/integrations/hosts/codex/install.sh

这个按钮做不了这件事：它要在没有仓库的 .app 上也能用，所以只做不需要仓库、 又绝对安全的那部分。

上面那条只带得到“这一回合结束了”。想让猫知道这件事是关于什么的， 还要把 MCP server 也加上——它跑在仓库里，所以这一半得你自己粘贴（<repo> 换成你的路径）： 

[mcp_servers.lingxi]
command = "node"
args = ["<repo>/packages/mcp-server/src/index.mjs"]

[mcp_servers.lingxi.env]
LINGXI_AGENT = "codex"
LINGXI_AGENT_NAME = "Codex"

权限与日志

界线划在会不会留下来，不是划在重要不重要。表情播错了四秒后就没了； 而一次 visible: false 会让你的猫消失，还看不出是哪个 agent 干的。 所以表演类（表情、动作、说话、玩具、任务事件）是 performer 就能做， 会保存下来的设置（主题、视角、大小、显示） 和写入备忘 / 提醒，要 trusted。

新 agent 默认是 performer——白名单的意思就是没列就不给。 这会改变以前的行为：之前任何 agent 都能改设置。被挡下的调用会在响应里说明原因， 也会记进下面的日志，不会静默。

行为预设

这个是真的：切换预设会立刻改变猫在"工作模式"下离光标多近才会避让（avoidRadius）。

玩具

放下玩具后，猫会把它当成当前唯一想做的事——优先级高于游走和避让，只输给你亲手拖它。 毛线球有真实物理（会滚、减速、撞边反弹），猫够到就拍一爪把它打飞，所以不用你管它也能自己玩下去。

说话

漫画气泡，钉在头顶。也可以让 Agent 通过本地接口说话（见调试台的 Agent 接口页）。

特效

几秒钟的整屏演出：走位、身体动作、表情、镜头和屏幕特效一起编排。特效层不接收任何鼠标事件， 演出期间你照常点按钮、切窗口都不受影响。

大小

自定义滑杆（0.25–1.0 连续）是文档里的提案，需要先放开 Rust 端的取值白名单，这一版还是三档。

视角

视角决定摄像机离地面多高。以前固定在接近俯拍的角度，基本只看得到猫背和头顶；现在默认「游戏视角」 （3/4 斜视），并且可以随时换。选「自动」时：站着/被撸/追鼠标 → 平视对上眼，走动 → 切回 3/4，切换是渐变不是硬切。

自定义资源

动作、表情、主题都是可编辑的 JSON 文件，放在应用配置目录的 assets/ 里，改完点「重新加载」即可生效， 不用重新编译。每个文件都会先完整校验再生效——格式不对时保留内置版本并在下面显示原因， 不会出现半张脸或者关节拧断的情况。手绘贴图（身体图集 / 表情图）放 assets/textures/。
