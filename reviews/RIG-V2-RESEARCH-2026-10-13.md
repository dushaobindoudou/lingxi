# 灵犀骨架 v2：脸部联动、眼部体积与爪部关节研究

日期：2026-10-13。用途：为 v2 规格提供解剖依据、最小控制建议与视觉目标；本文不修改冻结的 v1。

## 1. 结论与证据边界

目前的主要缺口是**成片的软组织变形、眼部的包覆结构，以及趾间关节**。局部控制幅度乘 2.5，不能替代胡须垫与上唇的体积、口角至颊的连续牵拉，也不能从薄眼皮生成眼窝。

建议分三项立项：

- 脸：在 v1 上最少增加 **9 根变形骨**，对应双侧胡须垫、双侧上唇片、双侧颊、双侧下眼眶软组织、中央鼻梁。耳根皮肤若无法通过现有 Ear 骨过渡，再增加 2 根，共 11 根。局部褶皱与体积保留需要配套修正形态。
- 眼：保留 Eye 与眼睑控制语义，改为有体积的眼球、独立角膜、厚眼睑、内眦与眼眶包覆。优先几何，再处理材质；不能只增加高光。
- 爪：四爪的 16 个主趾各加一根中节代理骨，是动作收益最高的第一步；独立收放爪还需要每趾一个 P3 末节旋转自由度。前爪狼爪另计，腕垫不需要独立骨。

证据分为三层：**[解剖]** 是猫的结构或观察研究；**[推断]** 是从结构与外观推导的皮肤联动；**[设计]** 是灵犀的参数、预设与实现选择。下文所有毫米数、耦合比例、时序与骨数均为设计起点，不是测得的猫肌肉生理参数。

已只读核对 [rig-v1.json](rig-v1/rig-v1.json) 与 [face-controls.json](rig-v1/face-controls.json)：骨数 86；已包含 Head、Jaw、Eye、上下 Lid、Ear/EarTip、Whisker、BrowIn/Out、MouthCorner、LipUp、NoseSide、Nostril、中央 LipUpper 与 LipLow。眼睑动作是形态键，凝视与瞳孔包含材质控制。`mouth.hiss` 已同时调用开颌、提上唇、鼻皱和 MouthWide，说明“已有动作名称”不等于“已有相应的整片变形”。小范围高斯、浅圆顶眼与爪尖伸出形态键的诊断来自本次用户/Claude 提供的信息；本文没有重新审计网格或权重。

身份依据为 [正面脸参考](../assets/characters/lingxi/reference/lingxi-ref-face-closeup.png)。`angry.jpg` 左一是表情方向，右两张是缺陷例。提示中缺失的 `round-ze/target/act-sit.png` 未作为证据或生成输入。

## 2. CatFACS 编号：避免套用人类 FACS

下表按 Caeiro、Burrows、Waller 的原始论文正文 §3.1.1、Table 1（PDF 印刷页 14–17、37–38）核对。CatFACS 描述可见动作，不把一个动作等同于一种情绪。原始论文确认猫鼻皱和上唇上提难以独立区分，应联合编码。[原始论文及表格](https://pure.port.ac.uk/ws/portalfiles/portal/5970434/Development_and_application_of_CatFACS.pdf)

| 需要表达的动作 | 本文使用的猫代码 | 规格上的含义 |
|---|---|---|
| 鼻皱 + 上唇上提 | **AU109+110** | 人类 AU9/10 的猫适配；不是两个完全独立的情绪开关 |
| 唇角向耳方向牵拉 | AU12 | 包含向后分量，不是单纯向上微笑 |
| 下唇下压 / 上提 | AU16 / AU17 | 与开颌分开控制 |
| 唇角向前、向口中线集中 | AU118 | 猫的收口外观；避免做人类噘嘴 |
| 唇分离 / 下颌下降 / 大幅撑口 | AU25 / AU26 / AU27 | 不能把三者都压成一个开颌旋转 |
| 胡须后收 / 前伸 / 上举 | AU200 / AU201 / AU202 | 不把 AU200 泛指所有胡须运动 |
| 上睑提高 | AU5 | 扩大眼裂；不等于瞳孔扩大 |
| 完整闭眼 / 短眨 / 半眨 | **AU143 / AU145 / AU47** | AU43、AU45 是人类代码；静态眯眼不自动等于动态 AU47 |
| 瞬膜显露 / 瞳孔扩大、缩小 | AD48 / AD68、AD69 | 属于 AD，不新增为表情 AU |
| 耳前向、内收、压平、旋转、下移、后向、收拢 | EAD101–107，依上述顺序 | 本次后压主要拆为 EAD103 + EAD104 + EAD106 |

猫的额/眉艺术控制不能直接宣称为 AU1/2/4；本表也不将 `CheekLift`、`OrbitLower` 冒称为已验证的猫 AU6/7。这些是生产控制名称。

## 3. 面部肌肉与皮肤：驱动 → 被动牵拉

### 3.1 解剖锚点与名称差异

猫的肌肉插入皮肤、唇和胡须垫的纤维组织；并非只在骨之间传力。Reighard & Jennings 的解剖图 63–64、印刷页 97–108 可直接追踪这些连接：[猫解剖原著](https://www.gutenberg.org/cache/epub/58394/pg58394-images.html)。以下结构描述据该原著；历史肌名与现代命名不是严格一对一。

| 肌肉/结构 | 解剖牵拉对象与方向 | 对灵犀的意义 |
|---|---|---|
| 鼻唇提肌 levator nasolabialis；旧称提上唇鼻翼肌的一部分 | 连接鼻翼侧皮肤、上唇与胡须垫 | 鼻翼、鼻侧、上唇和口鼻体积应有连续过渡 |
| 提上唇肌 levator labii maxillaris；旧著上唇方肌的角头/levator labii superioris proprius | 眶前缘附近起，扇形纤维进入胡须垫与上唇 | 提唇应带动一片口鼻组织，不能只提两个小点 |
| 犬齿肌 caninus | 上颌侧面至胡须垫 | 参与口鼻与胡须垫变化；单独肌名不能规定全部胡须方向 |
| 颧肌 zygomaticus major | 口角至耳前腱膜/盾状软骨区域，沿背后方走向 | 嘴角要向外、向后，并拉长口角至颊的皮肤带 |
| 口轮匝肌 orbicularis oris | 唇周肌纤维，与周围肌群混合 | 提唇、收口、展口要共享唇周组织，不能彼此撕开 |
| 颊肌 buccinator | 深层支持颊黏膜，连接唇周结构 | 颊张力/压扁与表层颊上提分开；不是自动生成鼓颊的肌肉 |
| 胡须垫肌群 | 外在肌移动垫块，毛囊周内在肌改变胡须姿态 | 垫块运动 + 胡须相对垫块运动，两级控制 |
| 眼轮匝肌 orbicularis oculi | 上下睑环带闭合 | 眼睑闭合应牵动眼周皮肤，下睑有参与 |
| 额肌/颅顶肌与猫的眉区肌带 | 额部、耳前与睑周组织相连；旧著内侧眉肌可提高上睑 | 不能把人类“皱眉肌收缩=眉头下压”直接移植到猫 |
| 耳肌群：adductor auris、abductor auris、levator auris、depressor conchae 等 | 盾状软骨与耳根、耳廓周围；不同组协同内收、外展、抬起、降低和后向 | 耳旋转/压平需带动耳根过渡皮肤，避免耳朵像独立铰链；不把一个 EAD 等同于一根耳肌 |

现代猫颊肌解剖研究补充其束走向与口角支持关系，提示旧教材的简化动作标签不能当成完整运动模型。[Tomo 等，猫颊肌解剖研究](https://digital.library.adelaide.edu.au/items/c101ba95-04a2-4376-b6e0-454dcab6675f)

特别注意：不要把啮齿动物的 nasolabialis/maxillolabialis 节律性 whisking 数据当成猫的已验证配比。本任务无需假设猫具有相同的主动扫须节律。

### 3.2 哈气/咆哮目标的联动图谱

下面箭头是**用于制作目标的因果近似**。AU 表示可见结果；“被动”指该区可随周边变形被带动，不表示真实猫完全不主动收缩该区。

| 联动 | 主动驱动 → 被动牵拉 | 范围、方向、修正要点 | 动作对应 |
|---|---|---|---|
| 提唇—鼻皱 | 提上唇/鼻唇提肌系统 → 上唇整体上卷 → 胡须垫上缘抬高、鼻侧缩短、鼻梁皮肤聚拢 | 上唇至鼻侧的两片扇形区域；向上、略后；鼻梁出现短横褶，不靠把鼻子整体抬大 | AU109+110 |
| 胡须垫堆积 | 垫块上提与后收 → 垫块上缘向眼下堆积、下缘拉长 → 胡须根随垫块移动 | 整个白色口鼻隆起，左右分开；向上/外/后；鼓起是压缩和体积保留，不能均匀放大 | AU109+110 的伴随外观；胡须后收另对 AU200 |
| 横向咧嘴 | 颧肌方向的口角后拉 → 唇侧边拉长 → 外侧胡须垫与颊皮肤向耳前延伸 | 嘴角至耳前连续带；向外、向后，少量上提；中线人中保持 | AU12 + AU25 |
| 颊—下睑 | 表层颊上移、眼轮匝闭合 → 下眼眶软组织聚拢 → 下睑被托起、眼裂收窄 | 下眼眶至外侧口鼻的大区域；向上；眼眶外圈承担过渡，睑缘贴合眼球 | 生产联动；半眨/闭眼按 AU47/143/145 的动态条件判断 |
| 开颌—下唇 | 二腹肌等开颌系统 → Jaw 旋转 → 下唇/下颊随动；下唇下压额外露出下牙 | 下牙、下牙龈刚性跟 Jaw；下唇可相对 Jaw 下移；上犬齿不能跟 Jaw | AU26/27 + AU16/25 |
| 眉额—眼裂 | 眉区艺术控制向内下压 + 上睑斜压 → 额部皮肤过渡、上睑上方遮挡增强 | 眼上至额部，范围宽于眉点；不做人类粗眉毛与深眉弓 | 艺术增强；不命名为猫 AU4 |
| 耳后压—耳根 | 多组耳肌协同 → 耳廓后向/压平/外转 → 耳根至太阳穴的皮肤滑移 | 耳根小环带和耳前过渡片；额部只弱随动，不能把整个头拉扁 | EAD103/104/106 |
| 胡须姿态 | 胡须相对垫块后收 → 须干靠向颊侧 | 毛囊根仍固定在垫块；与提唇可解耦，不能因垫块上提就强制全部须尖上举 | AU200；前伸/上举另为 AU201/202 |

“上唇上提 → 胡须垫上鼓 + 鼻梁皱 + 下睑上推”可以作为咆哮的制作链，但**最后一步应是弱的邻区传递，再叠加独立眼轮匝/颊控制**。没有依据将整条链写成猫的固定反射或单肌必然作用。

### 3.3 情绪预设与联动顺序

Bennett 等观察到哈气、掀唇、鼻皱、开颌和撑口与挫折相关；恐惧也可伴随眨眼、半眨，不能一律做成瞪圆眼。[2017 年观察研究](https://pubmed.ncbi.nlm.nih.gov/28341145/)。Humphrey 等发现慢眨序列可参与猫与人的正向交流；这支持“满足”的温和眼部设计，但不能证明所有半闭眼都表示满足。[2020 年慢眨研究](https://www.nature.com/articles/s41598-020-73426-0)

| 制作状态 | 建议同时动作的区域 | 驱动 → 被动牵拉 | 建议时序（设计，不是生理定律） |
|---|---|---|---|
| 警告性愤怒、闭口低吼 | 耳向后、口鼻张力、轻提唇、眼周收紧 | 垫块后收 → 口角附近拉紧；弱提唇 → 弱鼻侧褶；闭合颌保持口形紧张 | 耳/凝视先建立，口鼻与眼眶稍后进入 |
| 张口哈气 | 掀唇、鼻皱、口角后拉、下颌张开、耳后压；眼可窄也可偏宽 | 掀唇 → 鼻侧压缩/垫块隆起；展口 → 颊带拉长；开颌 → 下唇随动 | 先口鼻紧张，再开颌；不让下颌领先形成哈欠 |
| 本次“咆哮”艺术目标 | 在哈气上增强颊上提、下睑挤压、眉内侧斜压 | 口鼻 + 眼轮匝共同驱动 → 整片脸连起来 | 推荐过渡总长 0.20–0.35 s，眼/耳 0–20%，垫块/提唇 10–60%，开颌 25–100% |
| 警戒恐惧 | 耳后压/侧转、胡须后收，眼睑提高或快速眨眼；无防御哈气时唇可闭合 | 上睑提高 → 上眼眶皮肤展开；后收 → 垫块略扁；如转入防御哈气，再加入掀唇链 | 先凝视/耳，后决定瞪眼或保护性眨眼；不要锁定一种眼形 |
| 满足/放松 | 低张力口鼻、松耳、温和半眨/慢闭眼、自然下垂的胡须 | 眼轮匝低强度闭合 → 下眼眶轻托；口鼻释放 → 垫块恢复圆润 | 0.4–1.2 s 缓入眼部，停留后缓开；不调用咆哮的强颊抬升 |

瞳孔由照度、唤醒等共同影响；恐惧与愤怒均不应固定为针状瞳孔。身体弓背、炸毛、尾势与声音影响情绪可读性；本次四张图只覆盖脸/眼/爪。

## 4. v2 最小脸部骨/控制建议

### 4.1 尺度、坐标与权重规则

统一头宽 300 mm、鼻宽 34 mm、眼径约 78 mm。**眼径在本文暂按眼球直径解释**；若项目给的是眼裂可见宽度，应先确认再放大球体，而非直接照抄 78 mm。

位置以鼻尖/鼻中心近似锚点为原点，X 为角色自身右，Y 向头后，Z 向上；左右遵循 v1：`.L` 是 X 负侧，`.R` 是 X 正侧。v1 `Nose.head` 约 `(0,-381,480)` mm，可做转换起点：世界近似坐标 = 本表坐标 + 该锚点。**鼻骨 head 不保证等于网格鼻尖**，所有点还须投射到实际表面内 2–5 mm，不能直接当 Blender 放置清单。

以下半径均是软组织表面的测地影响范围。通用衰减：内核半径 `r0` 内保持平滑高权重，`r0..r1` 用 smoothstep 衰减到零；按区域遮罩归一化，并保留 Head 基础权重。不要用跨空气间隙的欧氏高斯影响对侧脸、上下唇或眼球。父骨不代表肌肉起点；这里是变形代理骨。

**这些骨均直接父到 Head**，避免把提唇、垫块、颊设成多级父子后又重复相加驱动。它们的联系通过控制求值与权重重叠实现。未来将 `Whisker.L/R` 的根部跟随相应垫块（可重挂父骨或矩阵约束，但二选一），保留须干相对运动；该操作属于 v2 实施建议，当前 v1 未改。

### 4.3 必须复用但重新定义影响片的 v1 控制

| 现有骨/控制 | v2 建议覆盖范围与职责 |
|---|---|

| 骨/控制 | 位置、父骨、范围 | 条件与收益 |
|---|---|---|
| `EarRootSkin.L/R`（2） | 耳根前下皮肤，锚点约 `(∓92,+150,+112)` mm；Head；r0/r1 10/35 mm | 现有 Ear 权重无法兼顾旋转和太阳穴过渡时加入；只弱随动，满幅后 2–3 mm |
| `OrbitUpper.L/R`（2） | 上睑外皮上方 8–12 mm；Head；r0/r1 8/28 mm | 眉区控制仍无法维持厚睑折叠时加入，勿替代现有 Blink 键 |

### 4.5 一个“咆哮”控制的定量耦合

定义 `Snarl S∈[0,1]`。下表的百分比是**各通道新定义的满幅**，并非直接可写入 v1 JSON 的数值；平移毫米见前表。Jaw 满幅先定义为张开约 30°，再按口腔碰撞调校，不能与 v1 `JawOpen` 值混用。

| 通道 | S=1 的目标权重 | 耦合意图 |
|---|---:|---|
| UpperLipSheet 上提/外卷 | 1.00 / 0.85 | 先得到整片掀唇与露龈 |
| MuzzlePad 上提 / 后收 / 体积修正 | 0.80 / 0.65 / 0.80 | 垫块隆起并后拉，白色口鼻仍有体积 |
| NoseBridge 压缩 / 鼻褶修正 | 0.75 / 0.85 | 短褶在鼻根，不抬整个鼻子 |
| MouthCorner 后拉 | 0.85 | 建立宽口形和颊侧张力 |
| CheekLift | 0.65 | 鼻口至眼下的连接层 |
| OrbitLower / LowerLift | 0.55 / 0.35 | 皮肤托举 + 睑缘贴球运动 |
| 上睑 Squint / LidSlantIn | 0.45 / 0.70 | 眼窄但仍读得到虹膜与高光 |
| BrowInnerDown | 0.60 | 卡通愤怒方向；鼻口仍是主读点 |
| Jaw 旋转 / LipLow 相对下压 | 0.70（约 21°）/ 0.60 | 展示上下犬齿，避免哈欠式大开口 |
| NoseSide / Nostril | 0.45 / 0.25 | 局部细节，防鼻宽失控 |
| 胡须相对垫块后收 / 上举 | 0.65 / 0.10 | 后收为主，上举轻微；须根随垫块 |
| EarFlatten / EarBackward / EarSwivel | 0.80 / 0.75 / 0.65 | 后压、外转；如有 EarRootSkin，弱驱动 0.25 |

可以给 `Snarl` 一个预设内的派生量：`PadLift=0.8S`、`CheekLift=0.65S`、`OrbitLower=clamp(0.25·CheekLift+0.39S,0,1)`。这把“颊上提带动眼下”表达为弱随动。**使用该公式时，不再叠加一遍表中的 0.55S**。控制图只单向求值：宏观状态 → 区域驱动 → 局部残差/修正；禁止区域互相驱动形成环。

必须保留 `LipCurl`、`MuzzleRetract`、`MouthRetract`、`CheekLift`、`Squint`、`JawOpen`、`EarPose` 的独立覆盖。这样才能做闭嘴愤怒、眼较宽的防御哈气，以及单侧掀唇。`Snarl` 不直接控制瞳孔。

预设混合建议先在状态层归一化愤怒/恐惧/满足权重，再逐通道限幅；Blink 对眼睑闭合优先，但不要覆盖全部颊部张力。所有通道可左右不对称，初始只给 5–10% 的差异。

### 4.6 不能只靠加骨的部分

1. **鼻褶**：需要横向可压缩的短鼻梁拓扑；轻褶用法线，轮廓可见褶用形态修正。长毛只能部分掩盖，不能把折叠线画在毛贴图上代替皮肤。
2. **胡须垫**：需要成对体积，留出上边堆积空间；MuzzlePad + UpperLipSheet 的组合形态要保容积，避免线性蒙皮压成纸片。
3. **上唇翻卷**：有外皮、唇内缘与口腔侧面，翻起后不能露黑洞。牙龈与牙齿固定在上颌，下牙固定在 Jaw；不能随唇一起被提起。
4. **口角**：上下唇在口角连续相接，展口与开颌组合不能裂缝。检验 `Snarl×Jaw`、`LipCurl×MuzzleLift`、`CheekLift×Blink` 的组合修正。
5. **毛发**：毛根随表皮区域运动；胡须有独立根与方向控制。只有短毛/皮肤版本能读出变形，再用长毛版检验遮挡。

## 5. 眼：可见结构与最小实现

### 5.1 解剖与可读性

猫眼是眼眶内有体积的球体，前面透明角膜有凸起；外睑包覆角膜/眼球，内缘与结膜湿润。内眦存在真正的凹角；瞬膜位于靠鼻的内侧、外睑之后。正常开放眼不应显露一大块瞬膜。[兽医眼结构说明](https://www.merckvetmanual.com/cat-owners/eye-disorders-of-cats/eye-structure-and-function-in-cats)、[Cornell 猫眼结构说明](https://www.vet.cornell.edu/departments-centers-and-institutes/cornell-feline-health-center/health-information/feline-health-topics/feline-vision-problems-host-possible-causes)

猫大角膜、较少眼白与瞳孔形状是重要身份特征；猫的瞳孔可从扩大时近圆变为收缩时竖缝。眼眶不能做成人类深眉弓。[兽医解剖教材：猫眼部分](https://elsevier-elibrary.com/contents/fullcontent/58986/epubcontent_v2/OEBPS/B9781416066071000116.htm)

“传神”依赖四类可见关系：**视线与球体转动一致；眼睑包球且有厚度；虹膜被上睑遮挡、投影；湿润反射与周围哑光毛皮形成差异**。内眦凹口、眼线和眼窝阴影帮助观众判断深度，不只是增加纹理复杂度。上睑可有很浅的皮肤转折，但不要求做成人类双眼皮或内眦赘皮。

### 5.2 灵犀的几何/材质起点（全部为设计参数）

| 结构 | 最小几何建议 | 材质/控制建议 |
|---|---|---|
| 眼球 | 直径暂定 78 mm 的完整/后部截球；大部分埋入眼眶；不能把整个 39 mm 半径球推出面部 | Eye 控制转动眼球/虹膜系统；眼球与表皮分网格 |
| 角膜 | 独立透明凸帽，与球体连续；相对基础球面再前凸约 2–4 mm，接缝藏在角膜缘 | IOR 起点 1.376、粗糙度 0.02–0.06；数值为渲染建议；统一环境高光，不画死高光 |
| 虹膜/瞳孔 | 虹膜放在角膜后约 1–2 mm，微凹盘；瞳孔不贴在外表面 | 虹膜径向细节、外缘较深；黑瞳孔有深度；材质凝视若继续保留，须与球体旋转同源 |
| 上下眼睑 | 至少外皮、圆润睑缘、内侧回折三个几何带；可见边缘厚度起点 1.5–2.5 mm，外侧皮层渐厚 3–5 mm | 眨眼沿球面包覆，上下睑共同闭合；睑缘保持贴球，避免眼球穿出 |
| 湿润内缘 | 约 0.3–0.7 mm 的窄带/泪液弯月面，下睑最明显 | 湿材粗糙度约 0.05–0.12；深粉棕色，少量半透；不要做成粗粉色香肠 |
| 内眦凹口 | 向内凹 2–4 mm 的小三角口袋，上下睑在此汇合；留出薄粉色组织与瞬膜空间 | 小而湿润，黑棕眼线延伸到凹口；不能用贴图黑三角代替体积 |
| 眼周色素/眼线 | 沿睑缘约 1–2 mm 细色素带，毛区边缘自然过渡 | 深棕而非纯黑粗描边；不做长人类睫毛 |
| 眼眶软组织 | 眼上、眼下、外眦形成浅包覆槽，皮肤不能与球帽同一平面 | 用几何遮挡与真实阴影优先，AO 只弱辅助，避免烘焙黑环 |
| 上睑转折 | 毛皮下很浅的 0.5–1.5 mm 转折，需要时随 Blink 改变 | 不画死褶线；正面可弱，斜视应读得到厚度 |
| 瞬膜 | 一片曲面藏于内眦，可沿角膜表面向外上覆盖 | 淡粉白，默认不大面积显示；AD48 独立，不与 Snarl 常态绑定 |

最小交付可不添加新眼部骨，利用 Eye 与上下睑键完成球体凝视、Blink、Wide、Squint；下眼眶软组织由新增 OrbitLower 承担。验收应看正面、3/4、侧面，以及上下左右凝视和完整闭眼。只有正面漂亮而侧面是贴片，不算补齐。

## 6. 爪：解剖、最少新增与动画收益

### 6.1 真实结构

前爪有五个指，II–V 为四个主要落地趾，各有掌骨 MC、近节 P1、中节 P2、远节 P3；I 为较高的内侧狼爪，只有两节趾骨。后爪通常四趾，使用跖骨；不要自动给后爪加狼爪。[猫解剖原著：Hand、Digits、Phalanges，图 51、印刷页 71–76](https://www.gutenberg.org/cache/epub/58394/pg58394-images.html)

爪的角质套附着在 P3。收爪是 P3 相对 P2 的旋转/侧向收纳：背侧弹性韧带帮助保持回收，屈肌系统参与伸爪，不能等同于“尖端线性伸长”。[Gonyea & Ashworth，猫科收爪机构研究](https://onlinelibrary.wiley.com/doi/10.1002/jmor.1051450208)。现代临床论文图 1 进一步说明 II–V 的偏心末节关节允许 P3 收至 P2 侧方。[末节关节解剖与图 1](https://pmc.ncbi.nlm.nih.gov/articles/PMC10811973/)

掌面需要区分四个趾垫、中央掌垫、较近端独立腕垫，以及内侧较高的狼爪垫。腕垫是软组织接触结构，不是第五个落地趾或独立关节。

### 6.2 v1 的局限与骨数方案

v1 每爪 Paw + Foot + 四个单节 Toe。Paw/Foot 可表达腕、掌区与整体跖趾方向，但不能同时表达四趾各自的 MCP/MTP、PIP、DIP。Toe0–3 是程序索引，后续须按网格内外侧映射到解剖 II–V，不能直接假定 Toe0 是狼爪。

| 层级 | 新增骨、位置与父级 | 动画收益 | 保留的局限 |
|---|---|---|---|
| 第一阶段：最低收益门槛 | 每主趾 `Front/RearToeMid0..3.L/R`，共 **16 根**；父为对应 Toe；枢轴在 PIP（从 MCP 到爪根约 55–65% 处，实际按趾形调整） | 原 Toe 表达近节，新 Mid 表达中节+末端代理；能卷趾、分段踩奶与抓握，不再四根直杆整体旋转 | P3 仍与 P2 合并；收放爪仍只是现有形态键近似 |
| 第二阶段：真正收放爪 | 每主趾 `ToeDist0..3` 再加 **16 根**，父为 ToeMid；枢轴为 P2–P3 的 DIP，固定刚性爪附于该骨 | P3 独立旋转，收爪侧藏、伸爪、抓物接触与舔爪近景更可信 | MC 仍由共同 Foot 代理，掌骨扇开较简化 |
| 前狼爪 | `FrontDewProx.L/R` 与 `FrontDewDist.L/R`，共 **4 根**；近节父 FrontPaw，末节父近节；位置在内侧高于趾排 | 舔爪、攀抓、持物时有第五个接触结构 | 不做对掌拇指，通常不参加平地承重 |
| 条件增强 | 每趾 MC 独立骨（最多四爪共 16 根），在掌/跖骨纵轴；父 Paw/Foot 按 v2 腕掌拆分决定 | 掌面展开、趾间扇开和落地适应 | 本次最小方案不必加入 |

第一阶段 Toe/Mid 的长度起点可参考 v1 单 Toe 约 34.6 mm；**不要把旧整根 Toe 保持原权重后又叠一根**。未来应将该段重分配为近、中末段代理，骨长度与关节位置以网格和真实爪轮廓为准。每趾影响限定在自身趾柱：趾轴向整段，横向内核约趾宽的 0.35、边界 0.7 倍，越过趾间沟快速归零；趾垫随本趾，掌垫主要随 Paw/Foot，不被单趾拉走。

第二阶段 P3 满幅伸爪可先用约 50–70° 的关节旋转试形，轴略斜于趾横轴以容纳侧藏，**这不是猫的实测关节活动范围**；以爪根、毛皮、邻趾不穿插为限制。不能再同时运行满幅爪尖伸出键，否则伸爪重复；原键可只承担爪鞘/皮肤形变。

| 动作 | 需要的自由度 | 第一阶段的收益与补充 |
|---|---|---|
| 踩奶 | MCP 与 PIP 依次屈伸、趾轻扇开、掌垫压缩；左右爪交替 | 每趾两段可先贴趾尖再压掌垫；趾垫/掌垫压缩用修正形态，不需垫骨 |
| 抓/抓挠 | 近节定位、中节卷曲、P3 伸爪、腕部带动 | Mid 能形成钩形；要读真实爪收放须第二阶段 |
| 舔爪/洗脸 | 腕屈曲与前臂朝向、趾展开、可见掌面 | v1 ForearmTwist 可辅助朝向，Mid 改善趾缝与接触；狼爪使掌面近景完整 |
| 握小物 | 四趾各自卷曲和展趾、爪与物体接触；狼爪辅助 | 控制每趾 `Curl/Splay/Claw`；不做人的握拳与拇指对掌 |

### 6.3 骨数预算（保留 86 根身份，新增代理骨计数）

- 脸核心 9 + 每主趾 Mid 16：总计 **111 根**。
- 上述 + 前狼爪 4：总计 **115 根**；这是脸与爪第一阶段的推荐预算。
- 如另加双侧耳根皮肤 2：总计 **117 根**。
- 四爪再独立 P3 16：分别为 **131 / 133 根**（无/有耳根皮肤）。

以上不计非变形控制器、约束辅助骨与可选瞬膜；如重构/替换 v1 原骨，须另列迁移账本，不能用本表声称兼容。
