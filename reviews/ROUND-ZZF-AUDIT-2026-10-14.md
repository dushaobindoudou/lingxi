# Round ZZF 审计：趾瓣降高与贴地（2026-10-14）

## 证据与判定口径

对照用户给的 `zzf-paw.jpg` 四行三列图（目标 / ZZD / ZZF：爪正、爪侧、坐后脚、站正），并查看 `v6/round-zzd/fc/` 与 `round-zzf/fc/` 的四张原始带毛图，以及上一批 `v5-imagegen-sources/paw_front_target_overlay.png`、`paw_side_target_overlay.png`。叠图红线是带毛目标，蓝线是皮面目标；前爪模板是 0.16 m / 1024 px，不能把拼图中照片的透视和缩放当作模型毫米数。另核对 `HANDOFF.md` 末节及两轮 `review-gait.json`。本审计没有重跑 Blender，也没有 ZZF 的全套 31 张姿态图；以下动态接地结论只在引用现有扫描时成立。

**总判定：ZZF 修好了“降趾瓣就离地”的实现错误，正面高竖棱缩短，侧面出现较清楚的圆趾端；造型尚未达到目标。** 正面下缘四趾仍合成一条宽软垫，三道谷的毛缘起伏太浅；侧面仍是长楔形的趾端加高掌，肉垫从底下露粉；坐后脚仍读不出分趾和承重掌底。站正缩小时没有显著姿态回归，但该图不能替代爪特写或整套动作验收。

## ZZD → ZZF 逐项核实

| 核对项 | 实际变化 | 距目标及判定 |
| --- | --- | --- |
| 趾瓣高度、底部接触 | `HANDOFF` 记录 `V6_MTOE_H` 为原高 ×.55，并让 `MTOE_Z` 同步下移；相同半径缩小而中心不动的 ZZE 试法曾使底部抬高约 13 mm、接触帧归零。ZZF 正面毛面底部没有出现整排爪悬起。 | **机制修复成立。** ZZD、ZZF `review-gait.json` 的 Walk / Run / Jump 各足接触帧数和同点滑移数逐项相同；Walk 的 `sole_low_mm` −2.99→−1.91，Run / Jump −1.45→−0.40 mm。它证明扫描口径下没有新的离地回归，不证明照片里每段掌底都视觉承重。 |
| 四趾是否成为底部圆鼓 | ZZD 从爪面中上部就有四道长竖棱；ZZF 的深色竖痕起点下移，趾端更像一排矮鼓包，两个中央趾比过去容易分出。 | **部分达到。** 目标照片与正面叠图要求四颗各有独立下弧的圆趾；ZZF 两侧趾仍横向摊开，中央四趾的毛边几乎连成水平线，站正小图里仍像整片袖口。坐后脚的近端圆块尤其没有四趾读数。 |
| 三道趾间沟 | ZZF 的皮面竖棱被压短，但正面仍见三条向上延伸的棕灰阴影，底边三处凹口很浅。 | **未过。** 上批红色正面目标的三个谷，按相邻趾端最低点计约 **6.7–7.7 mm** 深；内部指示线应只占底部约 **14–20 mm** 高。ZZF 毛缘未形成那样的三道明确谷。先量 1024 同机位的连续毛边，不能把毛色阴影当作谷深。 |

## ZZF 之后最该先改的 5 项

以下数值是下一轮**试形与验收门槛**，不是已经量到的 ZZF 实值。固定相机、正交尺度及地线，先存同机位带毛/去毛图，再按数值核验。

1. **前爪与坐后脚：分出四颗底部趾球，同时修下部外扩和掌底。** 在 1024 正面模板把三处连续毛边谷深做到 **6–8 mm**、趾间阴影的上端限制在趾端上方 **14–20 mm**；四颗趾各有独立下弧，坐后脚至少能辨 **3 颗**。同机位正面带毛爪/腿最宽比试 **1.15–1.20**，各高度红线轮廓误差控制 **±5 mm**；只局部收下部外翼，不按旧“−26 mm”估计整爪等比缩。侧面让趾端由楔形退后试 **5 / 8 mm** 两档，掌底接触段连续、最低离地 **0–3 mm**，粉色肉垫不得低于白色毛缘 **>1 mm**；复拍 `paw-front/side`、`sit-hindfoot`、`stand-app`，并重跑 Walk / Run / Jump 接触帧数，不能以加深沟换来离地。
2. **挠耳：先把两前掌压回支撑面。** 交接记录的旧挠耳两前掌离地约 **17 / 45 mm**、后足到耳 **46 mm**；下一轮把两前掌底各压到 **0–5 mm**、骨盆世界侧滚限制 **±0.10 rad**，后足到耳根 **≤25 mm**，保住当前抬正后的头高（相对当前不下降超过 **20 mm**）。正/侧机位同时显示两只支撑掌和触耳后脚，再做动态帧扫描。
3. **蜷睡：闭合尾巴在脸前的外环。** 以 `sleep-app/top` 同一姿态，把 `Tail0–4` 沿臀—腹外侧—前掌前缘走世界路径，尾尖落在下巴**前方 10–25 mm**、离地 **5–15 mm**；全路径不超过现有尾可达长约 **474 mm**，尾毛与身侧保留 **8–15 mm** 可见缝。俯视不得从腹下抄近路，露在环外的后爪向内收 **30–50 mm**。
4. **侧卧：放低后半身并重解四肢，而非只下压胸。** 在 `sidelie-app/top` 同一解里试骨盆/腰/胸世界滚转 **70–85° / 45–65° / 20–35°**；后两掌最低 **0–5 mm**、后腹/臀毛最低 **0–10 mm**，胸下缘约 **20–30 mm**，前两掌最低 **0–5 mm** 且中心相隔 **45–70 mm**、不交叉。两机位都要呈目标的头右尾左、后腿分层贴地，不能只在一个角度把臀藏住。
5. **头型：鼻端局部试前推，维持已收的额。** ZZD 同机位侧影的额只超前目标 **2.5 mm**，stop / 下巴仍超前 **10.7 / 14.8 mm**，鼻革落后约 **15 mm**；ZZF 未动头。以 `V6_NOSE_FWD` 做 **0 / +5 / +10 / +15 mm** 四档带毛和去毛侧影、正面及三分之四图，仅推鼻革—人中上端及相邻皮面。采用档的目标是鼻尖剩余投影差 **≤5 mm**，stop 和下巴各自不得比当前再前冲 **>2 mm**，正面双口鼻垫仍分开；不能把整块口鼻前移来追鼻尖。

其中第 2–5 项的基线来自 `HANDOFF.md` 与先前姿态/头型审计；ZZF 只提供四张爪相关静帧，下一轮须重新拍摄对应姿态才能宣布这些项目通过。
