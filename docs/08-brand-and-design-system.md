# 灵犀 Lingxi：品牌与设计系统

2026-09-11。用户已明确选定产品名「灵犀」；仓库使用 `lingxi`。旧材料中的「陪陪」保留为概念历史，不再作为产品名。英文采用拼音 Lingxi，含义来自“心有灵犀”：不用一直说话，也能感觉到陪伴。名称不等于商标或域名已获独占权；正式发布前另做名称检索。

## 视觉基准

用户明确纠正：需要“非常治愈”，且必须符合原始角色图。唯一主形象依据为[原始概念板](source/peipei-concept-board.png)左上主猫：灰棕虎斑与暖白、白色面部与小爪、圆脸、湿润榛绿眼、小粉鼻、蓬松毛、安静趴着、轻轻歪头。不要用纯白蜷睡猫、陶瓷摆件或抽象宠物图形替代。

初稿深绿底纯白猫已被用户否定；文件保留仅供追溯，不得作为默认图标。当前[图标 v2](../assets/brand/lingxi-icon-v2.png)按参考重做，尚待用户进一步视觉反馈。

## 图标与字标

图标保留脸、两只前爪和完整耳朵，暖奶油背景，避免房间布景分散注意。大尺寸展示毛发与湿润眼睛，小尺寸以脸型、眼睛和白爪识别。菜单栏需要后续独立制作单色符号，不能把复杂图标直接缩到 16px 当作完成品。

字标使用「灵犀」与小号 Lingxi，系统中文字体，中等字重、自然字距，不用书法花体和科技字体。品牌短句：**你忙你的，我在这里。** 设置文案温柔但简短，不替用户判断心理状态。

## 界面语言

[设计变量](../assets/brand/design-tokens.json)为当前可消费数据。整体采用暖白底、浅燕麦面板、深棕文字和低饱和暖杏强调。绿色只用于稳定状态的小范围提示；不再用大片深松绿决定整个品牌气质。

| 元素 | 规范 |
| --- | --- |
| 布局 | 一个主操作、充足留白、设置分组清楚；主屏优先展示猫 |
| 字体 | 系统字体 / PingFang SC；正文 14px，辅助 12px，标题 22px |
| 间距 | 4、8、12、16、24、32、48 |
| 圆角 | 控件 10px、面板 20px；避免满屏胶囊 |
| 按钮 | 文字明确：隐藏、换装、安静模式、任务观察；不隐藏退出入口 |
| 状态 | 图形加文字，不仅靠颜色；未知/断连不能显示成功 |
| 动效 | 控件约 160ms；面板 220ms；减少动态时关闭非必要动画 |
| 可访问性 | 键盘操作与焦点可见；系统字体缩放；正式 UI 检查文字对比 |

建议设置页分四组：陪伴（大小、位置、互动频率）、外观（皮肤）、性格（独立配置）、任务观察（平台、连接状态、提醒开关）。界面只解释用户决策需要的内容，骨骼、协议、LLM 参数留在开发工具。
