# 已知问题与支持范围

核对日期：2026-10-19。适用于准备中的 v1.0.0。这里记录仍存在的产品限制，不代表对应 GitHub issue 已完成验收。

## 使用限制

- **平台**：只支持 macOS 12+。原生窗口、光标与托盘使用 AppKit，当前没有 Windows / Linux 安装包。
- **多显示器**：光标坐标换算仍依赖主屏高度；副屏，特别是排列在主屏上方或下方时，需要单独验证。v1.0 的首发验收以主屏为准。
- **动作**：部分蜷缩动作中，腿与躯干仍有几何重叠；行走尚未实现完整的世界空间 IK，极端姿态可能出现脚部穿插。
- **系统光标**：玩具绘制在光标附近，系统鼠标箭头仍然可见。
- **签名与公证**：没有 Developer ID 和 Apple 公证的构建首次打开会被系统拦截。按对应发布说明在「隐私与安全性」中放行。v1.0 候选构建的实际签名结果以 BUILD_INFO.json 为准。
- **宿主差异**：仓库插件可安装与官方目录上架是两件事。事件支持与配置以各宿主文档及实际安装版本为准。

## 仍需实机验收

自动化测试不能替代以下验证。发正式版前应在另一台 Mac 或新 macOS 用户下完成：

1. 从通用 DMG 安装、首次启动、菜单栏开关、拖动、尺寸、主题与方块猫 / 写实猫形态切换。
2. 从旧版升级，设置、记忆、提醒和已有 Agent 配置保留。
3. Apple 芯片与 Intel 两个平台的启动及睡眠恢复。
4. Claude Code 和 Codex 各完成一次真实会话，验证来源图标、授权等待和回合结束不重复。
5. 主屏上的拖拽、玩具、锁屏恢复、提醒；副屏坐标按上面的限制记录。
