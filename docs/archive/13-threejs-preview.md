# Three.js 动作预览

2026-09-11。用户希望直接观察最新模型的实时立体与动态效果。本轮在第三版 Blender 试作基础上制作了交互页面。

**[打开私有动作预览](https://lingxi-cat-motion-preview.mergedao.chatgpt.site)**。已完成私有发布，访问者限定为项目所有者。

## 可操作内容

- 拖动旋转，滚轮或双指缩放，正面 / 侧面 / 背面切换和视角重置。
- 持续呼吸，自然眨眼；单独触发眨眼、摆尾和轻微转头。
- 暂停 / 播放、动作速度、毛发显示开关、暖白 / 深色 / 灰色背景。
- 系统减少动态偏好下默认暂停，仍可手动播放。

## 实际使用的资产

输入为 `lingxi-anatomy-study-v3.blend`，通过官方 Blender MCP 的后台调用导出，不修改原文件。保留原网格几何，抽样 93,137 根原生毛发曲线，每根以三段线显示。共有 45 个渲染记录、约 38.8 MB 模型数组，分为不大于 16 MiB 的文件加载。

渲染使用固定版本 `three@0.186.0` 和 OrbitControls，依赖与 MIT 许可随页面保存，不依赖运行时 CDN。导出脚本在[export_three_preview.py](../../scripts/blender/export_three_preview.py)，导出证据在[threejs-export.json](../evidence/threejs-export.json)。原始导出后添加了分块步骤，最终脚本已包含该步骤。

## 与成品的边界

程序材质转换为近似顶点色，线条毛发没有 Cycles 的发丝散射和完整厚度。实时页面的外观不能被称为 Blender 等效还原。

呼吸通过身体缩放、摆尾与转头通过部件枢轴、眨眼通过眼部缩放与覆盖实现。网格和对应毛发一起运动，但尚未完成四足骨架、蒙皮和眼睑变形。这些是动作效果试验，不是生产角色绑定。

当前模型本身的视觉问题仍见[角色试作验收](12-character-study-review.md)，新增动态不代表造型已经通过验收。实时帧率、功耗与桌面透明叠层尚未做系统测量。

## 验证与保存

页面 JavaScript 语法校验通过；所有模型数组检查了偏移、长度、数值有限性及身体/头/脚/尾/双眼覆盖。页面和模型依赖在本机返回 HTTP 200。没有进行浏览器截图或自动交互测试，不能声称动画经过视觉验收。

页面包含渐进启用的 WebMCP 动作控制入口；本环境未验证其注册与调用。不支持该接口不影响普通按钮和鼠标操作。

交互预览为独立的私有 Sites 项目，源码不与主仓库混合。项目 ID 及本地继续方式见[预览目录说明](../../previews/README.md)。

## 与 v4 的差距（2026-09-12）

本页描述的预览资产仍来自 v3；[v4 试作](12-character-study-review.md)（新眼睛结构、柔和面纹、新耳朵、分层加密毛发、24 骨骨架）**尚未**导出到这个预览。原因：该预览托管在 ChatGPT 的 Sites 产品上（域名 `*.chatgpt.site`，由 `previews/threejs/.openai/hosting.json` 记录项目 ID），是另一个会话/工具用那套发布能力创建的；当前 Claude Code 会话没有这个发布通道，只能更新本仓库里的源文件和本地 `dist/` 产物，无法把新版本重新发布到那个域名。另外 v4 的毛发总量（约 116 万根、40 个毛发对象）比 v3（214,819 根、12 个）大得多，即使导出脚本按对象抽样上限也会让模型数据显著变大，需要先决定采样上限和分块策略再导出，不能照搬 v3 的参数。
