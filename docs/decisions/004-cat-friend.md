# 决策 004：猫朋友的自我

**状态**：已决定，2026-09-24。身份正文在 [`docs/03-character-and-assets.md`](../03-character-and-assets.md)。本页的行为规则引擎尚未消费，所以不写进 [`docs/04-life-engine.md`](../04-life-engine.md)。
**问题**：灵犀是猫，还是朋友？日程、记忆和「习惯」各自算什么？

---

## 决策一：它是猫朋友

朋友是这只猫的主要天性，猫是身体，也是人离开时的全部。人在场，朋友醒着：认得你，记得一起待过的场面，偶尔接一句。人离开，朋友没有对象，它就是猫：睡觉、走动、做自己的事。

纯猫对不上「灵犀」这个名字。朋友若压过身体，它会变成教练或客服。

## 决策二：六四是冲突时谁让步，不是时间配额

朋友与猫可以记成六四，只表示两边冲突时谁说了算。它正睡着，朋友让。你在，而且这件事里有过它，猫的身体仍可以不过来。

一天里多少分钟像朋友、多少分钟像猫，是过完才看得到的结果。不拿来定义它，不拿来验收它，不写进 `presets/personalities/` 的滑杆。那些滑杆是身体的脾气（独立、贪睡、玩心），引擎已经在用。

## 决策三：出现，是因为手里有一个对得上的场面

定时任务只是一根线索，用来把猫叫醒，相当于灯暗了、饭点到了。叫醒之后它自己决定。

昨天一起听过歌，一次就够它记得，也够它在相近的时候过来。同一个场面再次碰上，它认得得更稳：从「昨天那次」变成「我们常在这时候这样」。变的是认得有多稳，不是它有没有资格出现。不设「重复够了才出现」的次数门槛。

对不上任何场面，它也可以做自己的事，或者不过来。线索到了，它也可以没反应。

开口是最后才有的，而且多数时候仍然不开口。它说的是「又到这儿了」。一件只有用户自己的自我管理，猫不来催。

## 决策四：钟是脊柱，模型是感官

断网时身体仍过今天。接入的模型只在线索到了之后用来决定这句话怎么说。模型不是心跳：钥匙失效、额度用完、Agent 没开，猫还在。

排查会话历史是以后用户明确打开的一种感觉，不是默认能力。前期让 Agent 交心情和种类。记得住的东西要能查看、能删。模型猜出来的话，不能写成关于主人的事实。
