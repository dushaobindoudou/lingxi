## R2 · "有名字就 trusted"实际上等于"拿到 token 就 trusted" —— 需要写清楚

`default_permission_for()` 让任何非 `anonymous` 的 id 默认 `trusted`。身份是调用方自己报的（请求头或
body 里的 `agent`），所以 `anonymous → performer` 这条只挡住"忘了报名字"的调用，挡不住任何人：报个名字就是
`trusted`。

这不一定是错的——能读到 0600 token 文件的进程本来就是用户自己——但它改变了权限档位的含义：档位现在防的是
**写得不好的 agent**（例如一个不该改主题的 agent 改了主题），不是**不该有权限的调用方**。建议：

- 在 `docs/19` 的权限一节和主界面的说明里直接写出这一点（主界面的说明文字工作区里已经在改）；
- 若以后要防后者，需要"用户在界面上批准过的 id 才 trusted"，而不是"报了名字就 trusted"。

## R3 · Cursor 用 `open -g -b` 启动应用 —— 已修

`open -b` 让 Launch Services 在所有登记过的副本里挑；开发机上它会挑中
`src-tauri/target/…/bundle/macos/灵犀.app` 这种构建产物（实际观察到了）。已改为先按
`/Applications`、`~/Applications` 的路径打开，`-b` 只作后备。DSH 插件、MCP server、CLI 同一天一起改了。
标准见 [`integrations/hosts/PLUGIN-STANDARD.md`](../../integrations/hosts/PLUGIN-STANDARD.md) A2。

## R4 · 用中文文案判断"这是不是生命周期事件" —— 可维护性

`is_lifecycle_summary()` 靠比对「会话开始」「本轮回复完成」「本轮因错误终止」等**显示文案**来决定要不要
压掉一句话。这些文案分别写在 `normalize_claude_hook_event`、Codex 的映射、`lingxi-emit.mjs` 里——任何人改
一处文案，抑制逻辑就静默失效，猫又开始说"本轮回复结束"，而且没有测试会红（现有测试只覆盖了这几个固定字符串）。

**建议**：`TaskEvent` 加一个结构化字段（例如 `lifecycle: true`），由各映射在生成事件时标记，判断改看字段。

## R5 · 24 个字符对英文太短

`BUBBLE_SAY_CHARS = 24` 按字符计。24 个汉字是一句完整的话，24 个英文字符只有三四个词
（"Fixed the login error m…"）。建议按显示宽度截断（全角算 2、半角算 1，上限 48），或按语言区分。
