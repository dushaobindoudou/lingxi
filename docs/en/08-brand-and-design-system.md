# Lingxi: Brand and Design System

2026-09-11. The user has explicitly chosen the product name Lingxi. The repository uses `lingxi`. 「陪陪」 in the old materials is kept as concept history and is no longer the product name. The English form is the pinyin Lingxi. The meaning comes from “心有灵犀” (hearts in tune): companionship can be felt without talking all the time. The name does not mean a trademark or domain has been exclusively secured. Do a name search separately before a formal release.

## Visual baseline

The user explicitly corrected this: it needs to be “非常治愈” (very soothing), and it must match the original character image. The only basis for the main image is the main cat at the upper left of the [original concept board](../source/peipei-concept-board.png): gray-brown tabby and warm white, a white face and small paws, a round face, moist hazel-green eyes, a small pink nose, fluffy fur, lying quietly, head tilted slightly. Do not replace it with a pure-white curled sleeping cat, a ceramic ornament, or an abstract pet graphic.

The first draft, a pure-white cat on a deep green ground, was rejected by the user. The file is kept only for traceability and must not be the default icon. The current [icon v3](../../assets/brand/lingxi-icon-v3.png) is designed backward from the actual in-app character: it keeps the gray-brown tabby, the warm-white inverted-V face, hazel-green eyes, a small pink nose, and two white front paws, and for the small Dock size it is pulled in to a quiet, soft, easily recognized front composition.

![Lingxi icon v3](../../assets/brand/lingxi-icon-v3.png)

## Icon and wordmark

The icon keeps the face, two front paws, and the full ears. It uses a separate rounded card on a warm-cream background, with the outside of the card transparent. That keeps a stable rounded silhouette under both the current Dock and the system rounded-corner mask. Large sizes show fur and moist eyes. Small sizes are recognized by face shape, eyes, and white paws. The menu bar uses a separately generated [monochrome PNG template icon](../../assets/brand/lingxi-tray-icon-v2.png): a round face, low ears, eyes, and a small nose form the minimum recognition unit. macOS tints it automatically for light and dark menu bars. The complex color icon is not simply scaled down.

The wordmark uses 「灵犀」 and a smaller Lingxi, a system Chinese typeface, medium weight, natural tracking. No calligraphic display face and no tech typeface. The brand line: **你忙你的，我在这里。** (You do your thing; I'm here.) Settings copy is gentle but short. It does not judge the user's psychological state for them.

## Interface language

[Design tokens](../../assets/brand/design-tokens.json) are the data that can be consumed now. Overall: a warm-white ground, light-oat panels, dark-brown text, and a low-saturation warm-apricot accent. Green is used only for small status hints of a stable state. A large field of deep pine green no longer decides the whole brand temperament.

| Element | Rule |
| --- | --- |
| Layout | One primary action, enough whitespace, settings groups clearly separated; the main screen shows the cat first |
| Type | System font / PingFang SC; body 14px, secondary 12px, title 22px |
| Spacing | 4, 8, 12, 16, 24, 32, 48 |
| Radius | Controls 10px, panels 20px; avoid screen-filling capsules |
| Buttons | The words are explicit: `隐藏` (Hide), `换装` (Change outfit), `安静模式` (Quiet mode), `任务观察` (Task observation). Do not hide the quit entry |
| Status | Graphic plus text, not color alone; unknown / disconnected must not display as success |
| Motion | Controls about 160ms; panels 220ms; when Reduce Motion is on, turn off animation that is not needed |
| Accessibility | Keyboard operation and a visible focus; system font scaling; formal UI checks text contrast |

Suggested settings page, four groups: `陪伴` (Companionship: size, position, interaction frequency), `外观` (Appearance: skins), `性格` (Personality: configured independently), `任务观察` (Task observation: platform, connection status, reminder switches). The interface explains only what the user needs in order to decide. Bones, protocols, and LLM parameters stay in developer tools.

## Character turnaround and asset status

The [turnaround candidate](../../assets/characters/lingxi/reference/turnaround-v1.png) was generated by the built-in imagegen from the original main cat, and has been packed into Blender. The front looks closer to a sitting pose, the side is a standing pose, and the view proportions and markings still need hand correction. It cannot be labeled as the final orthographic modeling blueprint. The Blender working scene has this limit written into it explicitly.

Every generation in this round used the built-in imagegen. Prompts are saved in the [generation record](../../assets/brand/generation-record.json). Generated references and the `.blend` working scene are not the same as a finished character with fur bound. Visual quality takes the original main cat as the target. The target is not lowered to accommodate a rough model.
