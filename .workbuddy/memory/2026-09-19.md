**发现的一个真实接口陷阱（已写进 interface.md）**
`POST /control` 的 `action` 和 `expression` 字段是**转发**的（Rust 不持有动作/表情词表，那是渲染器数据文件），
所以 id 拼错**不会报错**，`applied` 里标 `(forwarded)`、`rejected` 为空 —— `lingxi_express` 会报告成功但猫什么都没做。
对照：`perform` / `camera` / `skin` / `scale` / `toy` 是 Rust 侧校验、拼错会明确 400。
这条以前没人写下来过。
